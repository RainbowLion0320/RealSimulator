# RealSimulator · 王朝模拟器

从明朝皇帝的有限视角出发，探索信息、信任、权力与治理的模拟游戏。

玩家接触到的是大臣、身边人提供的消息，以及自己能够亲眼看到的事物；这些消息可能片面、滞后、错误，甚至被刻意隐瞒。

玩家负责关键决策与审阅，官员负责拟议方案和执行细节。玩法围绕定方向、用人、批复、追问与问责展开。

奏报与对话采用易懂的白话，保留称谓、礼仪和人物语气；按钮直接说明行动。

账面数据可能与地方实际状态不同，这种差异会影响决策和执行。确定从 1582 年张居正去世后、万历亲政的节点开始，使用丰富的预设文案与系统选项，不依赖运行时大模型对话。

系统不向玩家揭示真假、可信度、腐败度或其他隐藏评分。调查结果仍然是有具体来源的报告，由玩家自行判断。具体数值规则仍在讨论。

皇帝去世后可继续扮演继任者。时间平时自动推进，遇到需要决策的事情暂停，也允许玩家主动暂停处理政务；不要求逐日安排日常。

京城失守或丢失大片国土不直接结束游戏；只要皇室仍有能实际运转的政权，就可迁都、经营残局，并跨代尝试恢复。

允许大胆改革、发展技术并改变历史路径。内政、朝局、外交与战争追求同等深入的体验，共同遵守皇帝的信息与行动边界。

呈现以数值模拟和精心设计的 UI 为主，按需配插画。支持一局长期存档、慢慢经营，不以快速通关或紧凑节奏为目标。

新开局允许适度随机变化，避免成为固定解题流程。首个交付平台确定为本地网页游戏，在浏览器中游玩；如果需要本地服务或运行环境，提供便捷的启动入口。
