# RealSimulator · 王朝模拟器

从明朝皇帝的有限视角出发，探索信息、信任、权力与治理的模拟游戏。

玩家接触到的是大臣、身边人提供的消息，以及自己能够亲眼看到的事物；这些消息可能片面、滞后、错误，甚至被刻意隐瞒。

账面数据可能与地方实际状态不同，这种差异会影响决策和执行。计划从由盛转衰的历史节点开始，使用丰富的预设文案与系统选项，不依赖运行时大模型对话。具体年份和数值规则仍在讨论。
