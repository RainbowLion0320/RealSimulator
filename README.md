# RealSimulator · 王朝模拟器

从明朝皇帝的有限视角出发，探索信息、信任、权力与治理的模拟游戏。

玩家接触到的是大臣、身边人提供的消息，以及自己能够亲眼看到的事物；这些消息可能片面、滞后、错误，甚至被刻意隐瞒。

账面数据可能与地方实际状态不同，这种差异会影响决策和执行。确定从 1582 年张居正去世后、万历亲政的节点开始，使用丰富的预设文案与系统选项，不依赖运行时大模型对话。

系统不向玩家揭示真假、可信度、腐败度或其他隐藏评分。调查结果仍然是有具体来源的报告，由玩家自行判断。具体数值规则仍在讨论。

皇帝去世后可继续扮演继任者。时间平时自动推进，遇到需要决策的事情暂停，也允许玩家主动暂停处理政务；不要求逐日安排日常。
