# 大明王朝1582：文案标准

2026-09-24 用户确认：游戏名为 **大明王朝1582**；奏折使用现代语言，关键信息、关键词可保留时代特色。

- 先说明发生什么，再说明影响，最后说明希望皇帝决定什么。
- 使用短句和日常词语：“已经发出，但还没收到”“钱不够”“需要再给一些时间”。不让玩家先翻译古文才能决策。
- 保留陛下、臣、奴婢、内阁、户部、军饷、诏令、奏折、行在等身份和制度用语。较少见的词在首次操作说明中解释，例如“行在，也就是朝廷的临时驻地”。
- 数字、提出请求的人、消息时间必须清楚。正文可以通俗，但不能把大臣的说法变成旁白认证。
- 用“地方官说”“前线将领报告”，不用“当地实际已经……”提前公开隐藏状态。
- 选项直接描述行动及批准预算，不预告成功率或“腐败下降”。
