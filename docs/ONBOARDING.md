# 亲政引导与开放节奏 · v0.2.0

新局先从同一份“宁夏军饷未至”开始，以一件事串起操作。固定的是学习顺序，不固定玩家批示、执行成效或真假结论。

| 阶段 | 玩家操作 | 开放与边界 |
|---|---|---|
| 启程 | 开始亲政引导 | 仅案头和存档可用，时间暂停 |
| 1 读奏折 | 看来源、成文日、收文日、事情与金额 | 只呈现首份军饷奏折，暂不铺开其他来文 |
| 2 拟批示 | 自选发饷、查验、加强边防或暂缓 | 沿用真实政策，不指定正确答案 |
| 3 看记录 | 查看诏令簿 | 开放诏令页；主动施政、授权内阁暂缓开放。选择暂缓时说明为何没有拨款单 |
| 4 召见 | 向戚继光问山陕军务 | 开放召见；这一轮聚焦一个对象、地方和问题 |
| 5 等来文 | 点击继续时间 | 按日推进，召对记录到案后暂停；不是看到后台执行标志就提示完成 |
| 6 读回话 | 阅读答复 | 明确区分召对记录与批示执行回报，不把回话当核实 |
| 7 核旧文 | 进入档案、打开一份记录 | 开放档案。可直接翻回首份奏折；先实际打开文书，再继续 |
| 8 看地方 | 查看舆图、开始独立施政 | 开放舆图，完成后开放全部人物、提问、主动政策和内阁授权 |

引导固定一个下一步按钮在底部，正文可以独立滚动；未开放的导航写“稍后开放”。提示消息避开下一步按钮，打开弹层时不覆盖弹层操作。玩家边操作边认识入口。

## 存档与兼容

- 引导状态与报告引用写入同一份王朝存档，自动、手动、导入和 APK 共用。中途刷新或读档回到对应学习阶段。
- 已有 v0.1.0 存档不强行进入引导，不改世界状态。点击皇帝头像 → 开启新王朝，可以体验；原王朝照旧先备份到存档 3。
- 随时可跳过引导，立即开放全部系统；跳过不会撤回已经作出的决定，刷新后也不会重新拦截。
- 不改变初始账目、随机序列、命令执行和消息延迟规则。引导只限制当前界面入口并教会使用它们。

## 验证

`tests/tutorial.test.ts` 覆盖四种首轮批示、各阶段存档续接、尚未收到的来文不能触发完成、正常世界与引导世界一致、跳过、旧档、损坏的等待记录。

2026-09-24：共 25 项测试通过，类型检查和生产构建通过。网页实际走通暂缓分支至全部开放，并在批示记录、等候来文阶段刷新恢复；召对到达后停在 1582 年 7 月 2 日。新局、跳过及跳过后刷新实测通过。

Android 0.2.0 签名包实测覆盖升级保留旧局，开启新王朝后显示亲政欢迎页与锁定导航，原局备份到存档 3。320 像素窄屏实测拨款分支，提示消息不遮挡底部下一步。
