# v0.1.0 验证记录

验收日期：2026-09-24。对应游戏《大明王朝1582》，网页构建与 Android release 使用同一份游戏代码。此记录描述首版已验证范围，不等同于完整历史真实性或全部设备兼容性保证。

## 自动检查

`npm run check`：2 个测试文件、20 项测试通过，TypeScript 检查和 Vite 生产构建通过。

- 同种子与读档后结果一致；查看奏报不消耗随机数或改变世界。
- 实际库存、地方账本、已收到的报告分离；报告成文后冻结。正常公开视图不含隐藏属性、未到达消息或真实执行结果。
- 指令经过拨付、在途、执行和回报；钱粮不足会影响执行。银粮在定义的经济边界内守恒。
- 收到候旨报告才暂停；指令上限不妨碍选择暂缓；已有报告不会重复结算。
- 迁驻、继位、失去全部统治区域和三百年胜利边界有效。
- 存档完整性检查、旧文案迁移、压缩读写通过；迁移保持事实与随机状态。
- `npm audit --omit=dev`：0 项漏洞。开发工具链剩余提示见 [构建说明](BUILD.md)。

## 长局数值对照

三个固定种子分别跑放任、稳健经营、持续进攻三种简单策略，共九局；原始结果：[balance-v0.1.0.json](qa/balance-v0.1.0.json)。

| 种子 | 放任 | 稳健经营 | 持续进攻 |
|---|---|---|---|
| 17 | 42 年败亡 | 300 年存续 | 24.25 年败亡 |
| 29 | 39.92 年败亡 | 268.17 年败亡 | 21.08 年败亡 |
| 41 | 41.67 年败亡 | 300 年存续 | 20.92 年败亡 |

各局银粮守恒残差均低于 0.0000001（分别以万两、万石计）。三百年存档约 210 万个未压缩字符、17 万个压缩字符；四个本地槽的估算 UTF-16 占用低于 1.4 MB。

胜利只表示王朝存续，不代表百姓过得好或领土完整；两局存续的控制区域分别只剩一、二区。测试用策略不是最优玩家，也不能据此推断所有随机种子或长期平衡已经完善。人口、灾荒、战争、财税参数是游戏标定，后续仍需真实游玩反馈。

## 网页实际操作

在 Codex 内置浏览器操作生产构建，覆盖 320×740、390×844、1280×900；页面宽度与滚动宽度一致，没有横向溢出。图片完整加载，检查时无控制台 warning/error。

实测：五页切换、批示、时间推进至新奏报自动暂停、召见并等待回话、诏令状态、相关档案、按区域查来文、手动存档、刷新读档、导入 Android 导出文件、主动结束后公开真实数据、恢复之前的手动存档。结算实际库存与户部旧册报不同，正常游戏不显示这个差值。

预编译网页目录由其自带 PowerShell 服务启动（测试端口 5188），HTTP 200，页面与资源实际渲染。正式启动入口使用 5187。

网页版导出使用标准文件下载：点击及提示正常，但内置浏览器的自动化接口没有返回下载事件，本次未确认其落盘文件。这一项不记为完整通过；普通浏览器应在下载记录中确认文件。Android 系统文件导出和双端导入已确认。

## Android 实际安装

- 签名 release APK，包名 `com.rainbowlion.ming`，版本 0.1.0 / code 1，标签“大明王朝1582”；最低 API 24、目标 API 36，无 debuggable 标志。apksigner 验证 v2 / v3 签名通过。
- MuMu Android 15 中真实安装运行，1080×1920、density 440 竖屏检查。批示军饷后推进至 1582 年 7 月 13 日，外交奏报到达并自动暂停。
- 使用 `adb install -r` 升级最终包，7 月 13 日进度保留。
- 系统文件选择器成功保存 JSON；文件实际拉取并校验，随后在 APK 和网页中分别导入成功。
- Wi-Fi 与移动数据均关闭（读回状态为 0 / 0），强制结束后重新启动，页面与 7 月 13 日存档正常恢复：[断网启动截图](qa/android-offline-v0.1.png)。测试后网络与模拟器原显示设置均恢复。

尚未在实体手机、Android 7 或不同厂商系统逐一验收，不将最低版本声明当作这些设备均已实测。
